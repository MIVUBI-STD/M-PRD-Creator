# Maintenance Note Template

Use only when a maintenance note is genuinely useful; do not create one for every small fix.

```text
Problem:
Observed evidence:
Owner/root cause:
Scope:
Correction:
Proof:
Remaining limitation:
Next step:
```

Rules:

- keep one defect/boundary per note;
- link the canonical owner instead of copying its full content;
- distinguish implemented from verified;
- archive/supersede the note through current indexes rather than rewriting history.
