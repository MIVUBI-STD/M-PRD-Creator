# Repository Planning

This directory owns repository **work intent**, not implementation status, project/client requirements, approval, or proof. Current GitHub source and topic-specific commits remain authority for what was implemented.

- [Development](development.md): one active cross-owner development initiative and its boundaries.
- [Backlog](backlog.md): non-active proposals; never automatic work authorization.

Normal small fixes need no plan entry. Update a plan only when the future scope or accepted decision actually changes; do not create one note per commit. Project/client production packages remain in the ignored external/local workspace.
